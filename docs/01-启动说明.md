# Personal RAG 启动说明

本文用于第一次运行、日常开发和面试现场演示。

## 1. 环境要求

- Windows 10/11
- Python 3.11 或更高版本
- 可用的 DeepSeek API Key
- 第一次下载 BGE 模型时需要联网

## 2. 项目目录

所有命令默认在项目根目录执行：

```powershell
cd D:\idea\code\AI\Personal_RAG
```

## 3. 创建虚拟环境

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
```

不必强制激活虚拟环境，直接使用 `.venv\Scripts\python.exe` 最稳定。

## 4. 配置 DeepSeek

复制配置模板：

```powershell
Copy-Item .env.example .env
```

编辑根目录 `.env`：

```env
DEEPSEEK_API_KEY=你的真实密钥
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_BASE_URL=https://api.deepseek.com
```

不要把 `.env` 提交到 GitHub，也不要在聊天、截图或日志中公开 API Key。

## 5. 首次下载本地 Embedding 模型

后端使用 `BAAI/bge-small-zh-v1.5`。第一次在新电脑运行时，先执行：

```powershell
.venv\Scripts\python.exe examples\embedding_test.py
```

脚本会自动下载模型并输出：

```text
文字数量：3
向量数量：3
每个向量的维度：512
```

后端正式运行时只读取本地缓存，避免每次启动都联网检查。

## 6. 启动后端

打开第一个 PowerShell：

```powershell
cd D:\idea\code\AI\Personal_RAG
.venv\Scripts\python.exe -m uvicorn backend.main:app --reload
```

等待出现：

```text
Application startup complete
```

访问：

- API 状态：[http://127.0.0.1:8000/](http://127.0.0.1:8000/)
- Swagger：[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

## 7. 启动前端

打开第二个 PowerShell：

```powershell
cd D:\idea\code\AI\Personal_RAG
.venv\Scripts\python.exe -m http.server 5500 --directory frontend
```

访问：[http://127.0.0.1:5500/](http://127.0.0.1:5500/)

前端与后端是两个独立进程：

```text
浏览器 :5500 → FastAPI :8000 → DeepSeek / BGE / Chroma / SQLite
```

## 8. 推荐演示顺序

1. 打开前端。
2. 上传一个能用鼠标选中文字的 PDF。
3. 等待文档出现在知识库列表。
4. 提问 PDF 中可以明确回答的问题。
5. 展示流式回答和来源。
6. 删除文档，再刷新列表。
7. 打开 `/docs` 简单展示接口设计。

## 9. 运行数据位置

```text
data/uploads/        原始 PDF
data/knowledge.db    SQLite 文档目录
data/chroma_db/      Chroma 文本、向量和 metadata
```

这些运行数据都已加入 `.gitignore`。

## 10. 常见问题

### `uvicorn` 无法识别

使用模块方式：

```powershell
.venv\Scripts\python.exe -m uvicorn backend.main:app --reload
```

### Missing credentials

确认根目录存在 `.env`，且包含非空的 `DEEPSEEK_API_KEY`，修改后重启后端。

### 本地模型找不到

先执行：

```powershell
.venv\Scripts\python.exe examples\embedding_test.py
```

### 前端请求失败或出现 CORS

确认前端从 `http://127.0.0.1:5500` 打开，后端运行在 `http://127.0.0.1:8000`。不要直接双击 HTML 使用 `file://`。

### PDF 页数正常但文字为空

该 PDF 可能是图片扫描件。当前 `PyPDFLoader` 读取文字层，不提供 OCR；请换用文字型 PDF。

### 删除后仍检索到旧内容

早期版本写入但没有 `document_id` 的测试 chunks 不受新管理接口控制。确认测试数据不再需要后，再手动备份并清理 `data/chroma_db`，然后重新上传资料。

## 11. 停止服务

分别在前端和后端终端按：

```text
Ctrl + C
```
